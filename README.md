# 🎓 LabGen Bot — Telegram-бот для генерации отчетов по лабораторным работам

Интеллектуальный Telegram-бот, который превращает методические указания и задания в готовые академические отчеты формата `.docx` (Microsoft Word) с соблюдением ГОСТ, автоматическим решением задач, построением диаграмм и вставкой аккуратных математических формул.

---

## 🚀 Возможности

1. **Прием любых методичек:**
   - Поддерживает форматы `.pdf`, `.docx`, `.txt`, `.md`.
   - Автоматически извлекает текст задания до 80 000 символов.

2. **Индивидуальная настройка отчета:**
   - Генерация титульного листа по ГОСТ (вуз, кафедра, дисциплина, ФИО студента, группа, преподаватель, город, год).
   - Построение аналитических графиков и схем (через `matplotlib` с высоким разрешением 200+ DPI).
   - Оформление аккуратных формул Word (OMML XML) вместо некрасивого текста `$x^2$`.
   - Ответы на контрольные вопросы в конце работы.
   - Фильтрация лишней теории (фокус на практических расчетах и выводах).

3. **Двухэтапная генерация (LLM -> Python -> DOCX):**
   - Нейросеть генерирует чистый, самодостаточный Python-скрипт (`python-docx` + `matplotlib`).
   - Скрипт выполняется в изолированной сессионной папке пользователя.
   - Гарантируется 100% валидность Word-документа без поврежденных XML-тегов.

4. **Система самолечения (Auto-Heal):**
   - Если сгенерированный скрипт упал с ошибкой (например, несовпадение размерностей в графике), бот автоматически отправляет traceback обратно в нейросеть для исправления и повторяет запуск.

5. **Итеративное редактирование (как в диалоге):**
   - После получения отчета пользователь может написать: *«переделай формулы»*, *«замени преподавателя на Дьячкову»*, *«добавь выводы по пункту 3»*.
   - Бот модифицирует предыдущий скрипт и моментально присылает обновленную версию `.docx`.

## 📂 Структура проекта

```text
lab_bot/
├── bot.py               # Точка входа, запуск polling aiogram
├── config.py            # Настройки и загрузка переменных окружения из .env
├── prompts.py           # Системные промпты с правилами ГОСТ, стилями и формулами OMML
├── file_extractor.py    # Извлечение текста из .pdf, .docx, .txt, .md
├── runner.py            # Асинхронный запуск сгенерированного скрипта в песочнице
├── llm_service.py       # Универсальный клиент к OpenAI / OpenRouter / DeepSeek / Gemini
├── handlers.py          # Обработчики сообщений, файлов и итеративного диалога
├── requirements.txt     # Зависимости Python
├── .env.example         # Пример конфигурационного файла
└── README.md            # Данная инструкция
```

## 🛠️ Установка и запуск

### 1. Клонирование / Переход в папку
```bash
cd lab_bot
```

### 2. Создание виртуального окружения (рекомендуется)
```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

---

## ⚙️ Настройка `.env`

Создайте файл `.env` в корневой папке `lab_bot` (скопируйте из `.env.example`):

```bash
# Windows (PowerShell)
Copy-Item .env.example .env

# Linux / macOS
cp .env.example .env
```

Откройте `.env` в любом текстовом редакторе и укажите ваши ключи:

```env
# Токен бота Telegram, полученный у @BotFather
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Выбор провайдера нейросети: 'openai' или 'gemini'
LLM_PROVIDER=openai

# ==========================================================
# Настройки для OpenAI-совместимых API (OpenAI, DeepSeek, OpenRouter, ProxyAPI)
# ==========================================================
LLM_API_KEY=sk-...
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o

# Примеры альтернативных LLM_BASE_URL:
# DeepSeek: https://api.deepseek.com
# OpenRouter: https://openrouter.ai/api/v1 (модели: openai/gpt-4o, anthropic/claude-3.5-sonnet, deepseek/deepseek-chat)
# ProxyAPI: https://api.proxyapi.ru/openai/v1

# ==========================================================
# Настройки для Google Gemini (если LLM_PROVIDER=gemini)
# ==========================================================
GEMINI_API_KEY=AIzaSy...
GEMINI_MODEL=gemini-1.5-pro
```

## 📱 Пример взаимодействия с ботом

1. Нажмите `/start` в Telegram.
2. Отправьте файл с методичкой (например, `lab_7.pdf` или `lab_8.docx`).
3. В подписи к файлу или отдельным сообщением напишите:
   > Сделай титульный лист.  
   > Студент: Иванов Иван  
   > Группа: ИВТ-41  
   > Преподаватель: доц. Дьячкова О.В.  
   > Дисциплина: Проектирование и дизайн информационных систем  
   > Включи графики, аккуратные формулы Word и ответы на контрольные вопросы в конце.
4. Дождитесь генерации (бот пришлет готовый `result.docx`).
5. **Внесение правок:**  
   Напишите в ответ: *«В формуле 2 исправь индекс, а график сделай синим цветом»*.  
   Бот обновит код и пришлет исправленный документ.
6. Команда `/reset` сбрасывает текущий контекст и начинает работу с новым заданием.
